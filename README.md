# Dr. [Your Name] — Mental Health Awareness Website

A calm, trilingual (English / Hindi / Gujarati) public mental health awareness site. Static HTML/CSS/JS — no build step, no server required.

## Files Included
- `index.html` (Site structure)
- `styles.css` (Design, tokens, & colors)
- `script.js` (Interactivity, routing, & lang switches)
- `translations.js` (Site copy database)

## Quick Start
1. Edit `translations.js` to change your name and bio text.
2. Open `index.html` directly in any web browser to test locally!


## Interactive 3D Brain Atlas
- The Brain Atlas includes an optional, procedural 3D teaching model for selected surface regions and deep structures.
- Drag to rotate, scroll/pinch to zoom, use **Reset view**, and toggle surface/deep structures.
- The region buttons provide a keyboard-accessible alternative to selecting a mesh.
- The viewer loads Three.js from a pinned CDN at runtime. If the CDN or WebGL is unavailable, the text-based atlas remains available.
- The model is schematic and not to scale. It is not intended for diagnosis, imaging interpretation, or procedural planning.
